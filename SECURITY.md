# Security Policy

Research Memory is preparing for a closed macOS beta and does not yet publish a public
vulnerability intake address. Until one is established, report a suspected vulnerability
privately to the repository owner; do not include PDF content, paths, queries, notes, or
credentials in an issue.

Supported security fixes target the latest signed beta only. The v0.1 browser prototype is
unsupported and must not be exposed beyond loopback.

Reports should include the affected version, macOS version, reproduction steps using
non-sensitive fixtures, impact, and whether managed objects or backup files were involved.
Do not test with PHI or other regulated data.
